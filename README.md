# Indonesian Digital MSME & E-Commerce Sales Performance Dataset 🛍️🇮🇩

An automated dataset and interactive business analytics web dashboard tracking digital MSME (UMKM) sales performance, revenue trends, product categories, and customer satisfaction across Indonesia.

## 📊 Dataset Features
*   **Scope:** Digital MSME transactions across major Indonesian economic hubs (DKI Jakarta, West Java, East Java, Central Java, North Sumatra, Bali, etc.).
*   **Attributes:** Order Date, Province, Product Category, Sales Channel (Tokopedia, Shopee, TikTok Shop, WhatsApp), Unit Price, Quantity Sold, Total Revenue, Customer Rating, and Payment Method.

## 🚀 App Features
*   **Executive Metrics:** Real-time summary of Total Revenue, Total Orders, Average Order Value (AOV), and Customer Satisfaction Ratings.
*   **Revenue Analytics:** Multi-channel and category-wise breakdown visual charts using Plotly.
*   **Interactive Filters:** Filter data dynamically by province, sales channel, and product category.
*   **Raw Data Explorer:** Search, filter, and download raw tabular data directly from the browser.
